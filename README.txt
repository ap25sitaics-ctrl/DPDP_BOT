AIP-02 Deck Assistant: installable mobile web app (PWA)

1. Upload this whole folder (aip02-assistant) to the root of your GitHub repo:
   ai-osint-policing-toolkit/aip02-assistant/
2. Wait 1-2 minutes, then open on your phone:
   https://dixadholakiya.github.io/ai-osint-policing-toolkit/aip02-assistant/
3. Android (Chrome): tap Install app (or menu > Install app / Add to Home screen).
   iPhone (Safari): Share > Add to Home Screen.
4. After the first visit it works offline.

When you change index.html, change V="aip02-v1" in sw.js (for example to v2) so phones pick up the update.
